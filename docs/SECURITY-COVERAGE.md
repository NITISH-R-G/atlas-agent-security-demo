# Security coverage matrix

What each AI security issue is, what Atlas is meant to do about it, where it is implemented, which tests exercise it, and the result of the last run (402 passed, 11 live-provider tests skipped; skipped tests are not counted as passes). File names are under `src/lib/agent/` unless noted.

**Scope:** controlled, synthetic scenarios. This matrix is a record of what was tested, not a claim that every attack is prevented, and the project has not been independently penetration tested.

## Known and unresolved

- **Serverless state.** Approval single use, activity records and rate limits are per server instance on Vercel. A ticket replayed by its own session can reach another instance and repeat a *simulated* send. Fixing this needs a shared store, which was not added because it requires an external service. The app does not claim distributed single use, and no real message can be sent.
- The injection detector is a heuristic and misses paraphrases.
- The Security switch is a scenario setting, not authentication.
